# Модел 11 — „Логистична 3“ (само HERMES)

Основата е нормираната логистична (виж `docs/model-10-logistic2-analogs.md`, раздел „Основа“; модел 8 вече не е нормиран), с различна крайна вероятност.

1. Buy % на нормираната логистична за всяка свещ (нормирана логистична, TP/SL от настройките, смекчаване k = 25).
2. Линия = EMA(N) на този Buy %, `N = #inpAnalogAvg` (по подразбиране 200), `α = 2/(N+1)`.
3. Крайна вероятност = наклонът на линията: `d = линия[i] − линия[i−1]`, `tg = clamp(d·(N+1)/2·0.03, −0.9, 0.9)`,
   `Buy % = 50 + 50·tg`, Sell % = 100 − Buy %. Нагоре → Buy, надолу → Sell.

Старите модели не са променяни. Код: клон `modelIndex === 11` в `computeModelProbCore` (`models.js`). Не е в HEROS.
