# DiDemos

Уеб страница, в която хора от различни организации (общности) гласуват и споделят мнения по предложения.
Накрая **ИИ обобщава** резултатите: настроението на мнозинството, критиките и другите предложения.

Без външни зависимости — само Node.js 18+ (HTTP, `crypto`, JSON файл за данни).

## Бърз старт

```bash
cd didemos
node server.js            # http://localhost:3100
node test.js              # интеграционни тестове
```

Променливи на средата:

| Променлива | По подразбиране | Значение |
|---|---|---|
| `PORT` | `3100` | порт на сървъра |
| `DATA_DIR` | `./data` | къде се пази `db.json` |
| `ANTHROPIC_API_KEY` | – | ИИ обобщение с Claude |
| `OPENAI_API_KEY` | – | ИИ обобщение с OpenAI (ако няма Anthropic ключ) |
| `AI_MODEL` | `claude-sonnet-4-5` / `gpt-4o-mini` | модел на ИИ |

Ако няма ключ (или ИИ даде грешка), се ползва **автоматично обобщение без ИИ** (речник за настроение). То е
отбелязано като такова в резултата.

**Под Helious:** главният `server.js` монтира DiDemos на адрес `/didemos` (напр. `http://localhost:3001/didemos`),
със същия порт. Данните тогава са в `data/didemos/` (или `DIDEMOS_DATA_DIR`), а сесийната бисквитка е само за `/didemos`.
Самостоятелно (`node didemos/server.js`) работи на корена на порт 3100.

## Как се ползва

1. **Вход:** потребителско име и парола, или „Нямам профил“ → нов профил.
2. **Общности:** „Създай общност“ (име) → приложението генерира 8-знаков код (букви и цифри).
   Другите въвеждат кода в „Присъедини се“ и стават членове. Кодът се вижда на членовете на общността.
3. Сайтът има три панела:
   - **📰 Новини** — запитванията на общностите ти, най-новите първи. При отваряне се вижда пълният въпрос;
     отговаряш със свободен текст и/или отбелязваш един или повече отговора (според настройките на автора).
     Отговорът може да се промени по-късно.
   - **💬 Сподели мнение** — свободно (анонимно) мнение към общността или към конкретно запитване.
   - **➕ Създай запитване** — заглавие, пълен въпрос, по избор отговори за анкета (по един на ред),
     „повече от един отговор“ и „позволи свободен коментар“. Без отговори е само свободен текст.
4. **Обобщение (само авторът):** в отвореното си запитване авторът вижда броя отговори и бутона
   **✨ Обобщение с ИИ** — получава настроение, резюме, критики, други предложения и коментари.
   Може и да затвори запитването.

## Структура

```
didemos/
├─ server.js        HTTP сървър, API, сесии, хранилище
├─ ai.js            обобщение: Anthropic / OpenAI / резервно без ИИ
├─ public/          интерфейс (index.html, app.js, style.css)
├─ test.js          интеграционни тестове (node:test)
└─ data/db.json     данните (създава се сам, не се комитва)
```

## API (всички освен вход/регистрация изискват сесия)

| Метод и път | Какво прави |
|---|---|
| `POST /api/register`, `/api/login`, `/api/logout`, `GET /api/me` | профил |
| `GET/POST /api/communities`, `POST /api/communities/join` | общности и присъединяване с код |
| `GET/POST /api/surveys`, `GET /api/surveys/:id` | новини и създаване на запитване |
| `POST /api/surveys/:id/respond` | отговор (един на потребител, презаписва се) |
| `POST /api/surveys/:id/close` | затваряне/отваряне (автор) |
| `GET/POST /api/surveys/:id/summary` | последно / ново ИИ обобщение (автор) |
| `GET/POST /api/opinions` | споделени мнения |

## Сигурност и поверителност

- Пароли: `scrypt` със случайна сол; сесии в `HttpOnly` cookie; ограничение на опитите за вход.
- Достъп само до запитвания на общности, в които си член; обобщение и затваряне — само авторът.
- Авторът вижда отговорите само обобщено — **без имена** на гласуващите.
- Целият потребителски текст се показва чрез `textContent` (без XSS) и CSP забранява вградени скриптове.
- В заявката към ИИ текстовете на хората са маркирани като данни, не като инструкции. Ако ползваш ИИ,
  мненията се изпращат на избрания доставчик — съобщи го на потребителите.

## Ограничения

Данните са в един JSON файл — подходящо за малък брой общности. За по-голям мащаб сменете хранилището
(слоят е в `server.js`: `loadDb`/`saveDb`) с база данни. Няма възстановяване на парола и имейл.
